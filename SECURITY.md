# Security Policy

Signal-to-Action Planner is a Markdown-first repository. It does not operate a hosted service or collect user data.

## Supported Version

Security fixes are applied to the latest commit on `main`.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting:

https://github.com/fzfclee/signal-to-action-planner/security/advisories/new

Include the affected file, the risk, reproduction steps, and a suggested mitigation when available. Do not include confidential company, client, personal, medical, legal, financial, or safety-related data.

For normal documentation and methodology questions, use a public GitHub issue.
